# Cereal Catch

A big-screen game and trading-card maker for the *Lessons from the Frontier* session. It is one self-contained file, `index.html`: the fonts and icons are built in, so it makes no outside requests.

**Live at:** https://janvi618.github.io/gpd-ai-bingo/cereal-catch/

## What's in it

| Tab | What happens |
|---|---|
| **Play** | Type a name, press Play, and catch falling cereal with a spoon for 30 seconds. Rings are worth 1 point, marshmallow stars 3, golden rings 5, and burnt bits take 2 away. Eight catches in a row earns a bonus point per catch. Scores go on a top-10 leaderboard. |
| **AI Cards** | Answer four questions (name, role, something you're secretly great at, go-to cereal) and get a trading card with a hero name, superpower, stats and a quote. |
| **Card Wall** | Every card made, with Save image and a printable sheet (nine cards per US Letter page). |

## This copy vs. the Claude copy

| | GitHub Pages (this copy) | Claude artifact |
|---|---|---|
| Who can open it | Anyone with the link, no sign-in, phones included | Only the owner's signed-in Claude account |
| Card text | Written by a built-in template writer | Written live by Claude |
| Leaderboard and cards are saved | In that one browser | With the artifact, across the owner's browsers |

Claude only runs inside claude.ai, so the AI-written cards need the Claude copy. Everything else works the same here.

## Before presenting

Open Settings (gear icon) to add an optional team name for the card footers, play one round to check sound, then use **Reset leaderboard** and **Clear all cards** to remove test entries.
